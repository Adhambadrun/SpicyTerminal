WHAT THIS PAGE KNOWS · AND WHAT IT DOES NOT

      
Seat Map: real flight, labelled layout

      

        
Real: the airline, flight number, route, date, cabin, booking class and aircraft type come from the itinerary you converted. The aircraft type's provenance is shown on the map.

        
Layout: the cabin configuration is labelled by tier. Verified means it was checked against that airline's own seat map; reference means it is the typical configuration for the aircraft type and has not been verified for the airline; generic means only the cabin cross-section is known. The badge on the map says which one you are looking at. Layouts are never invented to fill a gap.

        
Short version: the flight is real and the cabin layout says how well it is verified — no API key, no setup. When the seat actually matters, the airline's own site is where seats live — the link on the map walks you there.
